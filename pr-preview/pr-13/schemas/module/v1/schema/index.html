Type string
Required Yes

Description: Module name in namespace/name form (e.g., 'nf-core/fastqc', 'nf-core/gfatools/gfa2fa').

Restrictions
Must match regular expression ^[a-zA-Z0-9._-]+/[a-zA-Z0-9_-]+(?:/[a-zA-Z0-9_-]+)*$ Test
